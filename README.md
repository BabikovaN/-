# Pet HTML — гра, де діти вчаться робити сайти 🐱

Інтерактивний тренажер HTML для дітей 7–14 років. Дитина пише код зліва — і одразу бачить свій сайт справа. Котик Тег знаходить помилки, пояснює їх простими словами і підказує, як виправити.

**Демо:** https://babikovan.github.io/-/

## Можливості
- **Один екран: код + сайт.** Живий попередній перегляд у безпечному вікні.
- **20 рівнів у 5 світах:** текст → посилання й картинки → списки й таблиці → кнопки й форми → власний сайт.
- **Пояснення дитячою мовою**, приклад, завдання й 3 підказки на кожному рівні.
- **Розумна перевірка помилок:** незакриті теги, помилки в назвах (`<hl>` замість `<h1>`), забуті `>`, лапки, атрибути `href`/`src`/`alt`. Показує рядок, пояснює, що не так, і може виправити за дитину.
- **Котик-помічник у чаті:** відповідає на питання «Що робити?», «Чому помилка?», «Що таке `<img>`?» з урахуванням поточного рівня й коду дитини. Працює без інтернету.
- **Словник «з мови програмістів на дитячу»** — 39 термінів з поясненнями й прикладами.
- **Міні-тести** після кожного рівня, **великий іспит** і **сертифікат** з іменем дитини (PNG).
- **Мотивація:** досвід (XP), зірки, серія днів, 10 досягнень, котик отримує аксесуари.
- **Дві мови:** українська та англійська, перемикач у будь-який момент.
- **Реєстрація за поштою** (ім'я, пошта, вік). Кілька дітей можуть грати на одному пристрої.
- **Адаптивно:** комп'ютер, планшет, телефон (вкладки «Код / Сайт»). Звуки й анімації можна вимкнути.

## Технічно
- Чистий HTML + CSS + JavaScript (ES-модулі), без збірки й залежностей — відкривається на будь-якому хостингу, зокрема GitHub Pages.
- Код дитини показується в `iframe` з `sandbox` — без доступу до сторінки гри.
- Дані зберігаються в `localStorage`. Шар `js/storage.js` зроблено так, щоб легко підключити сервер (Supabase / Firebase) для акаунтів між пристроями, оплати й кабінету батьків.

## Структура
```
index.html          оболонка застосунку
css/style.css       дизайн
js/app.js           екрани: головна, вхід, карта, рівень, тест, словник, іспит, профіль, сертифікат, чат
js/levels.js        20 рівнів (uk/en): теорія, завдання, перевірка, підказки, тест
js/checker.js       пошук і автовиправлення помилок у HTML
js/assistant.js     котик-помічник
js/dictionary.js    дитячий словник
js/i18n.js          тексти інтерфейсу (uk/en)
js/storage.js       акаунти й прогрес
js/fx.js            звуки й конфеті
assets/             картинки для уроків
```

## Запуск локально
Будь-який статичний сервер з кореня репозиторію, наприклад: `python -m http.server 8000` → http://localhost:8000

## Варіанти для замовника
Модель продажу обирає замовник: безкоштовна версія, частина рівнів платно, разова покупка або ліцензія для шкіл і гуртків. Для оплати й акаунтів між пристроями потрібно підключити сервер (див. «Технічно»).
